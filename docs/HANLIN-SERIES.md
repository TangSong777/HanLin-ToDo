# HanLin 系列设计规范

2026-11-26 · Windows · 寒淋输入法、寒淋笔记、寒淋待办

## 应用图标

采用寒淋输入法 C 案「浅底『淋』」。三款窗口、任务栏、开始菜单、托盘应用入口和安装包取用同款多帧 ICO。

| 应用 | 识别字 | 字色 |
| --- | --- | --- |
| 寒淋输入法 | 淋 | 三点水 `#AA333C`，右侧「林」`#000000` |
| 寒淋笔记 | 记 | `#000000` |
| 寒淋待办 | 办 | `#000000` |

统一用米白底 `#F8F8F6`、珊瑚描边 `#CF6266`、造字工房悦黑常规体。圆角以外透明。字形按可见像素边界等比居中。Windows 输入状态保留「中／英」功能图标，应用入口用「淋」。

| 20 px | 0 px | 1.375 px | 3.625 px |

| 25 px | 0.625 px | 1.000 px | 5.500 px |

| 40 px | 1.000 px | 1.625 px | 8.750 px |
| 48 px | 1.125 px | 2.000 px | 10.500 px |
| 64 px | 1.500 px | 2.625 px | 14.125 px |
| 96 px | 2.375 px | 4.000 px | 21.125 px |
| 128 px | 3.125 px | 5.250 px | 28.125 px |
| 256 px | 6.375 px | 10.625 px | 56.375 px |

每帧以八倍画布 `N = 8 × S` 独立绘制。16、20、24、32 px 的透明留边为 0，圆角为 `round(N × 0.18)`，描边为 `max(11, round(N × 0.06))`。其余帧分别取 `max(2, N // 40)`、`round(N × 0.22)` 与 `max(8, N // 24)`。描边沿轮廓向内。小帧的字形宽高上限均为 78%，其余帧为宽 64%、高 65%。字形先用 BILINEAR 拟合，再以 BOX 缩回单帧成品。

## 应用界面

| 色彩角色 | 浅色基准 | 应用 |
| --- | --- | --- |
| 表面 | `#FFFCF9` | 内容卡片、表单、设置、菜单 |
| 标题晕染 | `#FAE8E6` | 对话框顶部，渐变到表面色 |
| 正文 | `#3C3C3C` | 标题、输入、次按钮文字 |
| 次级文字 | `#736460` | 字段标签、提示、元数据 |
| 主操作 | `#E48887` | 保存、新建和强调操作 |
| 主按钮文字 | `#000000` | 珊瑚底按钮 |
| 主按钮交互 | `#D58180` 悬停，`#CC7D7C` 按下 | 点击反馈 |
| 选中 | `#FCEEEB` | 分类、菜单和浅色高亮 |
| 常规交互 | `#F9E0DE` 悬停，`#F5D1CF` 按下 | 次按钮、菜单和拖动反馈 |
| 强调文字与焦点 | `#93444D` | 选中标签、键盘焦点、行内错误 |
| 轮廓与分隔 | `#E2DFDD`、`#F1EFEC` | 1 DIP 描边及分隔线 |

界面尺寸按 96 DPI 的逻辑坐标定义。120 DPI 时物理尺寸为逻辑尺寸的 1.25 倍。窗口圆角约 10 DIP，内容卡片 8 DIP，按钮与分类标签 7 DIP，输入框 5 DIP，菜单 10 DIP。类型标题可用悦黑，缺少该字体时使用微软雅黑 UI。设置正文为 13 DIP 左右，窗口标题约 18 DIP，字段辅助字约 12–13 DIP。常用线条图标画布 14 DIP，笔画约 1.25 DIP，使用圆端点。主要状态同时用文字、勾选或边框表达。

系列设置页以 **600 × 454 DIP** 为基准。顶部高 **46 DIP**，左置 **26 × 26 DIP** 应用字标与「设置」，右侧为关闭按钮。内容左右边距 **20 DIP**，顶部 **12 DIP**，标签高约 **32 DIP**、宽约 **72 DIP**、间距 **4 DIP**。标签下方有 1 DIP 分隔线，正文从分隔线下约 **16 DIP** 开始。底部主按钮靠右，常用按钮 **84 × 36 DIP**，取消与保存间距 **8 DIP**。字段多时在当前页内纵向滚动。各控件保持原生键盘语义，焦点用深珊瑚描边表达。

| 产品工作区 | 系列配色的应用 |
| --- | --- |
| 寒淋输入法 | 右击 Windows「中／英」入口进入统计、词库管理和设置。工具窗采用暖白、珊瑚与字标标题。全新安装采用 HanLin 暖白珊瑚候选窗，已有本机皮肤时优先读取。中文宋体，拼音和英文 Arial，基准 **16 px**，随 Windows DPI 缩放。 |
| 寒淋笔记 | 笔记库、文档、弹窗、菜单使用系列色板，保留原有浅色、深色和跟随系统选择。笔记库浅色画布为 `#F4EFEA`，深色画布和卡片为 `#1A1614`、`#221D1A`。正文可另选字体。页面转场 180 ms，跟随 Windows 动画设置。 |
| 寒淋待办 | 便签按 **236 × 411 DIP**、正文 **14 DIP**、圆角 **8 DIP**、任务行留白 **6 DIP** 初始化。便签里的颜色、字体和尺寸可调，设置窗用固定系列配色。新增、完成、排序等反馈采用 140 ms 淡出，跟随 Windows 动画设置。 |

## 设置与操作

| 标签 | 寒淋输入法 | 寒淋笔记 | 寒淋待办 |
| --- | --- | --- | --- |
| 常规 | 输入方案及编辑入口 | 笔记默认排序 | 登录 Windows 后自动显示便签 |
| 外观 | 显示主题来源、字体和字号 | 主题和正文字体 | 尺寸、界面比例、配色、字体、圆角、行距 |
| 数据 | 数据文件夹和进阶配置 | 数据文件夹、本地备份、回收站清理周期 | 数据文件夹、工作目录选择、打开任务文件 |
| 关于 | 产品、版本、词库搜索快捷键 | 产品、版本、快捷键和库统计 | 产品、版本和快捷键 |

- 入口统一叫「设置」。Notes 主窗和 ToDo 便签内支持 `Ctrl+,`，各自的通知区菜单也提供入口。IME 通过「中／英」菜单或开始菜单打开，ToDo 可从开始菜单直接打开设置。
- `Ctrl+F` 进入当前可见工作区的搜索。寒淋笔记在文档编辑区搜索当前文档，笔记库搜索全库。寒淋待办搜索便签任务，IME 在词库管理中搜索词条。
- 有可编辑字段时，修改先留在窗口里，点「保存」后一起生效。「取消」、关闭按钮和 `Esc` 放弃窗口内未保存的编辑。打开文件夹、查看关于等导航可直接执行。
- IME 设置页提供查看和进入配置文件的操作，底部为「关闭」。进阶设置在编辑器保存后，通过词库管理的「一键部署」生效。
- 菜单和对话框里的回收站、彻底删除、取消、保存分别使用相同中文动词。需要确认时，按钮写明具体动作，例如「删除」与「取消」。可恢复的记录放在对应产品的回收站里。

## Windows 安装向导

三款共享 `Brand/HanLinWizard.iss` 与简体中文语言文件。Inno Setup 用 Modern 浅色布局、暖白 `#FFFCF9` 背景和珊瑚品牌图。欢迎与完成页的侧图采用 **164:314** 构图，实际资源 **492 × 942 px**。过程页使用 **128 × 128 px** 透明 ICO 衍生字标。窗口标题、图标、侧图、中文动作与返回顺序属于共用向导。按钮与文件夹对话框使用 Windows 标准控件。 [Inno Setup 向导样式](https://jrsoftware.org/inno-setup/documentation/topic_setup_wizardstyle.htm) · [向导侧图](https://jrsoftware.org/inno-setup/documentation/topic_setup_wizardimagefile.htm)

用户依次看到欢迎、选择安装位置、确认、安装进度和完成页。输入法安装另外显示许可与第三方声明。可用「浏览」更换位置，用「上一步」返回确认目录，在完成页选择打开应用。安装器支持 Windows 10/11 x64。「应用」列表和开始菜单提供常规启动及卸载入口。

| 产品 | 权限与默认位置 | 用户数据 |
| --- | --- | --- |
| 寒淋输入法 | 管理员注册 x64 和 x86 Windows 文本服务，默认 `Program Files\HanLin`，升级读取已登记的位置 | 默认 `%APPDATA%\HanLin`，也可由现有 `UserDataDir` 指定。词库、方案、统计独立于程序安装目录。 |
| 寒淋笔记 | 当前用户安装，默认 `%LOCALAPPDATA%\Programs\HanLin\HanLin-Notes` | 程序旁的 `Data`。更新旧便携版时选择其现有文件夹，笔记随原目录使用。 |
| 寒淋待办 | 当前用户安装，默认采用已登记安装位置，其次用现有登录启动项定位便携版，再使用 `%LOCALAPPDATA%\Programs\HanLin\HanLin-ToDo` | 程序旁的 `data\todo.md` 或设置所选位置。个人设置在 `%LOCALAPPDATA%\HanLin-ToDo\settings.json`。 |

程序文件由安装器更新和卸载，旧数据可继续从原文件夹打开。Notes 仍可直接启动程序目录里的 EXE，ToDo 同时提供内含运行时的单文件便携 EXE。更换安装目录时，旧便携数据随原文件夹保留，可在需要时选择该目录。输入法词库在打包时使用暂存配置编译，可与桌面正在运行的输入服务并行。
